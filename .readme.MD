# PeerPath — Professional Networking Platform

A professional networking platform where users can build profiles, share posts, connect with people, and engage with their professional community.

## Live Demo

**Visit PeerPath:** https://peerpath-1.onrender.com

Explore the live application and try its features.

## Features

- **User Authentication** — Register, log in, and log out securely.
- **Profile Management** — Create and update your professional profile.
- **Posts and Feed** — Create posts and browse content shared by other users.
- **Likes** — Like and unlike posts.
- **Comments** — Add comments to posts and delete your own comments.
- **People Discovery** — Explore users and discover professionals.
- **Connections** — Connect with other users.
- **Notifications** — Stay informed about relevant activity.
- **Profile Pictures and Image Uploads** — Personalize your profile and share images.

## Tech Stack

- **Frontend:** React, Vite, React Router, Axios, Material UI
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Authentication:** Passport.js, Express Session, Connect-Mongo
- **Image Storage:** Cloudinary
- **Deployment:** Render

## Run Locally

### Backend

```bash
cd backend
npm install
```

Create a `.env` file in the backend directory:

```env
PORT=5000
MONGODB_URL=your_mongodb_connection_string
SECRET=your_session_secret
NODE_ENV=development
```

Start the backend using the script defined in `backend/package.json`, for example:

```bash
npm start
```

### Frontend

Open another terminal:

```bash
cd frontend
npm install
```

Create `frontend/.env`:

```env
http://localhost:5000
```

Start the frontend:

```bash
npm run dev
```

Open the local URL shown in your terminal, usually `http://localhost:5173`.
